## About

This repository is a simple, runnable script for practicing JavaScript arrays. It starts with a list of developer names and logs examples of reading, changing, and destructuring that list.

## Features

- Read array elements by index and inspect an array's length.
- Add an element by assigning to an index.
- Use array destructuring and the rest operator.
- Add and remove elements with `push`, `pop`, and `unshift`.
- Insert an element with `splice`.
- Check for values with `includes`.

## Tech Stack

- JavaScript
- Node.js (to run the script)

## Architecture

The project currently consists of one standalone script. It creates an array, performs several operations in sequence, and prints each result to the console. There are no external packages or services.

## Getting Started

1. Install [Node.js](https://nodejs.org/).
2. Clone this repository and open its directory in a terminal.
3. Run the script:

   ```sh
   node script.js
   ```

The examples and their results will be printed to the console.
